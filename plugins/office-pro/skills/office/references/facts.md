# 写进稿面之前的事实核查

> 本文件 = 调研结论如何进 pptx。禁止把未核数字留在用户要演示的页上。

## 纪律

1. **官方页优先。** 型号、发布日、参数、API 价：厂商 changelog、定价页、Hugging Face 模型卡。媒体「据悉」不当官方。
2. **榜单写清三件：哪张榜、哪一天、是否区间重叠。** 「曾登顶」可以；「稳居第一」要当时票数与误差。
3. **对不上就删数字。** 允许写「未复测」「未核官方价」。禁止用星级、幻觉率、靶场题数、综合倍率（如 1/40）充场面。
4. **不要发明 SKU。** DeepSeek 是 V4-Pro 与 V4-Flash 两档，不是「V4 Pro Flash」。Flash 与旗舰的算力门槛差一个数量级，表格里要分开。
5. **算力按权重体积，不按激活参数。** MoE 专家权重通常全驻显存。公开配方（8×B300、8×昇腾 910B）写成「公开配方/社区案例」，不要写成「官方最低配置」除非部署页原文如此。
6. **改完扫残留。** `query '*' --find` 扫旧型号、旧价、幻觉、综合倍率、留存天数、靶场分。命中就改或删。
7. **价和榜不过夜。** 上一次稿面的输出价、参数、登顶句不能原样抄进下一份。每次对官方页重取；对不上就删数字。

## 落地顺序

```text
列断言 → 每条标六态与出处 URL → 只把实证/有日期的公开榜写进 PPT → 截图核溢出 → query 扫旧词
```

厂商自述（「效率对标英伟达」「发现 N 个漏洞」）若必须出现，加「官方称」。默认不写。

## 六态（与 docs-evo 相同）

`[实证]` 已核对 URL 或本机命令；`[推断]` 由体积/算术推出；`[经验]` 历史惯例；`[记忆]` 建议复核；`[假设]` 待验；`[直觉]` 不进稿面。
