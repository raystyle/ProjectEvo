# 测试流程规范：双轴分层与五层正名

> 核心模型：**地基层**（框架原生：单元/集成/文档测试）与**意图层**（目的流程：冒烟/回归/验收/A-B）是正交两轴，「冒烟放哪个目录」是混轴的假问题。提炼自家族九仓实测 [实证： 2026-09-04 九仓文档与实盘双核对]。

## 一、双轴模型（先分轴再谈层）

- **地基层（框架原生）**：框架内置分类，决定**落点**与跑法：单元（源码同文件）、集成（独立目录、只走公开面）、文档测试（注释内代码块）；Rust `cargo test` 固定顺序跑三段，前段失败后段不执行，快测试挡住慢测试
- **意图层（目的流程）**：冒烟、回归、验收、A-B **不是框架概念**，靠组织约定加脚本载体加 CI 流程拼装 [实证： reader 仓 G006]

意图层不新造目录：复用地基层落点，用独立 test target、文件名或调度时机区分（如 `cargo test --test smoke`）。

## 二、五层正名

| 层 | 轴 | 回答的问题 | 典型载体 | 运行时机 |
| --- | --- | --- | --- | --- |
| 单元测试 | 地基 | 单函数对不对（私有 API、错误路径、不变量） | Rust `#[cfg(test)] mod tests`；pytest `tests/unit`；vitest `*.test.ts` | 本地门禁（每次） |
| 集成测试 | 地基 | 公开契约对不对（退出码、stdout 标记行、JSON 关键字段） | `tests\*.rs`（assert_cmd）；`tests/integration`；`tests/<域>.test.ts` | 本地门禁（每次） |
| 冒烟测试 | 意图 | 核心路径活着没 | 独立 target（`--test smoke`）；`npm run smoke`；Pester 结构冒烟；冒烟矩阵（退出码矩阵） | 门禁内；发版资产解包后；新平台首装 |
| 回归测试 | 意图 | 改动破没破旧行为 | 集成全网即回归网；黄金文件/快照基线；修 bug 附复现用例 | 动对应管线后；结构大改后断链回归 |
| 验收测试 | 意图 | 满足需求口径没 | BDD feature；POC example 作 oracle；真机真钥清单；verify 脚本 | 里程碑与发版前；方案验收步 |

- 层间取舍：**能用集成覆盖就不用单元**：集成不依赖内部结构，重构时更稳 [实证： 结构源仓 R004]
- 文档测试是地基层第三层（公开面小可暂不写，列入演进候选）
- 冒烟只断「活着」，质量判断归验收与 A/B [实证： reader 仓 G006]

## 三、断言纪律（跨栈通用，家族各仓 AGENTS 逐字一致）

1. **期望值来自独立来源**：规范、黄金文件、属性约束；不得用被测同款逻辑复述期望值、不得镜像实现分支。重言式测试按构造通过，纯噪声，AI 生成测试高发
2. **只断稳定字段**：退出码、标记行、机读码、JSON 关键字段；放过 pid、时间戳、请求 ID、机器差异
3. **一个测试一件事**；失败信息能定位（panic 消息带原因与实际值）
4. **正例负例成对**；负例名带 `dies_` 前缀可过滤；「无参数应失败并打用法」是标准负例
5. **错误路径必须覆盖**：空输入、缺文件、无 token、权限失败、超时；冒烟要覆盖「无 token 加无兜底」形态才能暴露绑定类缺陷 [实证： 云 CLI 仓 教训]
6. **测试体错误传播**（Rust 用 `TestResult` 加 `?` 代替 unwrap）；输出无序时双侧 sort 后比对
7. **不默认 mock**（mock 只进外部 API 边界）；计时进断言禁止；性能用基准工具不用断言

## 四、跨栈载体速查

| 栈 | 日常单测命令 | 冒烟载体 | 回归载体 | 慢测与真机闸门 |
| --- | --- | --- | --- | --- |
| Rust | `cargo test --locked` | `--test smoke` 独立 target | insta 快照、黄金文件 `tests\expected\`、语料基线 | `#[ignore]`；环境变量闸门（如 `OME_TEST_REAL`，缺则 skip 不失败不写真实态） |
| Python(uv) | `uv run --with pytest python -m pytest tests/unit -q` | stdin/import 冒烟 | mistake 编号配回归用例；防漂移单测 | conftest 钉临时 HOME 隔离真实数据；平台预期 skip |
| TypeScript | `npm test`（vitest run） | `npm run smoke`（--help 退出码）；冒烟矩阵 | 修复配回归断言；断链扫描 | `it.skipIf(!外部依赖)`，skip 不伪造 |
| PowerShell | Pester `tests\*.Tests.ps1`（结构冒烟） | 模块导入、布局存在性、DryRun no-throw | verify 脚本重跑全 PASS 即回归 | 提权/实机路径不进 Pester，走实机清单 |

## 五、门禁时机谱

1. **本地门禁（每次）**：Rust 三件 `cargo fmt --all -- --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test --locked`；Python/TS 单测 `-q`；文档件（lint、断链、字符扫描）。锁文件入仓，测试跑 `--locked` 防依赖漂移
2. **批次门禁**：PLAN 批次通过标准列门禁清单，每批次全绿才算过 [实证: ome 源仓 PLAN]
3. **CI 门禁**：push 与 PR 三系统矩阵（fail-fast 关），fmt 到 clippy 到 test 顺序串
4. **发版门禁**：三路全平台（本机、实机、CI）；「全平台验收绿是唯一放行条件」；资产解包后跑一次 `--version` 冒烟；self update 真升级路径首验 [实证： reader 仓 R008]
5. **收尾闭环**：verify（FAIL 即漂移）加 heal（幂等，可无脑重跑，重跑 verify 全 PASS 即回归） [实证： 主机环境仓 P0020]
6. **假绿防线**：任何 FAIL 必须 exit 1（验收命令全程 exit 0 属假绿）；空匹配断言（`-match ''` 恒真类）显式 FAIL 不静默过；验收命令不接吞退出码的管道 [实证： 主机环境仓、reader 仓 M006]

## 六、特色机制（按项目选配）

- **黄金文件 oracle**：输出多行带结构、逐行 contains 会放过行序/空行/缺失时升格全量比对；一测试一文件进 git；人工核对契约后冻结，变更走 diff 审查；归一化集中 helper；跨平台双 oracle [实证： ome 源仓 R004]
- **快照纪律**：新快照以失败形式产出 `.snap.new`，人工审后入库；CI 禁静默改快照 [实证： reader 仓]
- **回归生长律**：修 bug 必附一个能复现的用例；mistake 编号与回归测试一一对应 [实证： reader 仓、浏览器工具仓]
- **防漂移**：repo 源 == 打包母本；部署副本 sha256 == 源码 [实证： 浏览器工具仓、主机环境仓]
- **DryRun 沙箱**：写操作无确认旗标只预览不触真；测试只走 DryRun，配越界路径 Throw 断言 [实证： 虚拟化仓、PVE 仓]
- **A/B 对比**：是对比不是门禁；人裁决，结论回填 S 文档 [实证： reader 仓]
- **验收即对照**：期望值来自外部 oracle（旧实现/PRD/真机清单）；未覆盖显式声明，未实现显式 NOT_IMPLEMENTED [实证： 云 CLI 仓、结构源仓]
- **六态衔接**：测试绿是 `[实证]` 最强依据，断言可引测试名；未落地门禁项保持 `[记忆]`/`[推断]` [实证： ome 源仓 R004]

## 七、AGENTS「写测试时」摘要条款（模板）

- 可以：按双轴分层（单元进同文件或单测目录、集成进 tests 只走公开面）；意图层用独立 target 或命名区分；期望值来自独立来源；慢测与真机走闸门 skip 并说明，不失败不伪造
- 禁止：重言式断言；只测 happy path；默认 mock；计时进断言；测试设施无 feature gate 进生产构建；FAIL 静默 exit 0（假绿）
